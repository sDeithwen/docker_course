## Практическая работа №1: Знакомство с Docker
Цель: Научиться управлять жизненным циклом контейнеров, пробрасывать порты и работать с образами из Docker Hub.
Время на выполнение: 45 минут.
#### Базовые требования (Обязательно для всех)
1. Скачать образ веб-сервера nginx из Docker Hub.
2. Запустить контейнер с nginx так, чтобы он работал в фоновом режиме.
3. Настроить проброс портов так, чтобы при переходе в браузере по адресу http://localhost:8080 открывалась стартовая страница Nginx.
4. Продемонстрировать запущенный контейнер через терминал ( docker ps) и найти этот же контейнер в графическом интерфейсе Docker Desktop.
5. Остановить и удалить контейнер после проверки.
#### ⭐ Задание на 1 звезду (Конфликт портов и изоляция)
Запустить одновременно два контейнера Nginx.
Сделайте так, чтобы первый был доступен в браузере по адресу http://localhost:8080, а второй — по адресу http://localhost:9090. Докажите, что это два независимых веб-сервера, работающих на одном компьютере.
#### ⭐⭐ Задание на 2 звезды (Исследование Docker Hub и тегов)
Самостоятельно найдите на сайте hub.docker.com официальный образ языка Python.
1. Скачайте две разные версии (тега) образа: полновесный (например, python:3.11) и облегченный (например, python:3.11-alpine или slim).
2. Сравните их размер с помощью команды в консоли (разница должна быть в несколько раз).
3. Запустите облегченный контейнер в интерактивном режиме, чтобы попасть внутрь консоли Python, напишите там print("Hello from Docker") и выйдите.
#### ⭐⭐⭐ Задание на 3 звезды (Вторжение в контейнер)
Запустите nginx (как в базовом задании). Используя команду docker exec, зайдите внутрь работающего контейнера и измените стартовую HTML-страницу.
В результате, при обновлении страницы http://localhost:8080 в браузере, вместо стандартного “Welcome to nginx!” должен отображаться ваш собственный текст (например, “Hacked by [Ваше Имя]”).
#### Шпаргалка по полезным флагам:
На лекции мы разобрали базовые команды. Вот пара полезных ключей (флагов) для команды docker run, которые вам сегодня понадобятся:
- -d (detach) — запустить контейнер в фоновом режиме (чтобы он не блокировал вашу консоль).
- -p <порт_хоста>:<порт_контейнера> — проброс портов. Nginx внутри контейнера всегда работает на порту 80.
- -it (interactive + tty) — запустить контейнер в интерактивном режиме (чтобы вводить команды с клавиатуры).
- --name <имя> — дать контейнеру понятное имя вместо случайно сгенерированного.
  💡 Подсказка для 3 звезд:
  Стартовая страница Nginx внутри контейнера лежит по пути /usr/share/nginx/html/index.html. Вы можете перезаписать её с помощью команды echo "Ваш текст" > /usr/share/nginx/html/index.html.
