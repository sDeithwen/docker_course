## Финальное практическое задание: Многоконтейнерное приложение с PostgreSQL
Цель:
Объединить навыки сборки образов, работы с сетями, томами и переменными окружения для создания полноценного стека из трёх сервисов с разными способами запуска.
### Архитектура приложения
Вам необходимо реализовать стек из трёх компонентов:
1. PostgreSQL — база данных для хранения сообщений
2. Генератор сообщений (generator) — сервис, который каждые 5 секунд автоматически создаёт сообщения в БД
3. Интерактивная консоль (console) — CLI-приложение для ручного управления сообщениями

Все три компонента должны взаимодействовать через общую сеть.
#### Что нужно сделать
1. Собрать два образа для Python-приложений (generator и console) согласно требованиям
2. Настроить запуск и работу всех 3х сервисов 

### Сервисы
#### Приложение 1: PostgreSQL
- Образ: postgres:alpine
- Порт приложения: 5432
- Переменные окружения: POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB
- Путь хранения данных внутри контейнера: /var/lib/postgresql/18/docker

- Healthcheck: проверка готовности через выполнение команды pg_isready -U app_user -d app_db

- Ограничения ресурсов: CPU 0.5, RAM 512M
#### Приложение 2: Генератор сообщений (generator)
- Образ: собирается из generator/Dockerfile
- Переменные окружения: DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD
- Сеть: должен быть подключен к сети с PostgreSQL
- Зависимости: должен запускаться только после того, как PostgreSQL будет готов (использовать depends_on с condition: service_healthy)
- Рабочая папка внутри контейнера: /app
- Команда запуска: python app.py
- Установленные библиотеки: tortoise-orm, asyncpg
	- Устанавливать через pip install tortoise-orm asyncpg

#### Приложение 3: Интерактивная консоль (console)
- Образ: собирается из console/Dockerfile
- Режим запуска: интерактивный, с флагом -it
- Переменные окружения: DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD
- Сеть: должен быть подключен к той же сети, что и PostgreSQL
- Зависимости: требует запущенный PostgreSQL
- Рабочая папка внутри контейнера: /app
- Команда запуска: python app.py
- Установленные библиотеки: tortoise-orm, asyncpg
	- Устанавливать через pip install tortoise-orm asyncpg
### Задания со звёздочкой
#### ⭐ 1 звезда: Комбинированный запуск
- Настроить запуск через два разных инструмента:
	- docker-compose up — запускает PostgreSQL и generator
	- docker run — запускает console с подключением к общей сети
- Продемонстрировать, что все три контейнера работают одновременно и взаимодействуют корректно
- Показать, что console может управлять сообщениями, созданными generator
#### ⭐⭐ 2 звезды: Использование Volume для сохранения данных
- Создать именованный том для хранения данных PostgreSQL
- Подключить этот том в сервисе postgres по пути /var/lib/postgresql/18/docker
- Продемонстрировать, что после выполнения docker-compose down и повторного запуска данные сохраняются
- Показать, что после docker-compose down -v данные удаляются
#### ⭐⭐⭐ 3 звезды: Использование кастомной сети
- В docker-compose.yml создать отдельную сеть (например, app-network)
- Поместить сервисы postgres и generator в эту сеть
- При запуске console через docker run подключить его к этой же сети
- Убедиться, что контейнеры могут взаимодействовать друг с другом по имени сервиса
- Продемонстрировать, что порты PostgreSQL не опубликованы на хост (отсутствует ports), но контейнеры всё равно видят друг друга
